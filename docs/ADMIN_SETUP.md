## 처음 한 번만 하는 설정 (Firebase 콘솔, 약 5분)

### 1. 이메일/비밀번호 로그인 켜기
Authentication → **로그인 방법(Sign-in method)** → **이메일/비밀번호** → 사용 설정 → 저장

### 2. 관리자 계정 만들기
Authentication → **사용자(Users)** → **사용자 추가** → 이메일 + 비밀번호 입력
- `donkah16@gmail.com`
- `knockj.pla@gmail.com`

### 3. 다른 사람이 가입하지 못하게 막기 (중요)
Authentication → **설정(Settings)** → **사용자 작업(User actions)** → 「**생성(가입) 사용 설정**」 체크 해제 → 저장
> 관리자 계정은 콘솔에서만 만들 수 있게 됩니다.

### 4. 보안 규칙 교체
Firestore Database → **규칙** → 기존 내용을 전부 지우고 `firestore.rules` 내용 붙여넣기 → **게시**

### 5. 확인
`/admin/`에서 로그인 → 각 탭에서 시험 등록 → 사이트에 표시되는지 확인

> 이미지는 Firestore에 자동 압축해서 저장하기 때문에 **Firebase Storage(유료 Blaze 요금제·카드 등록)가 필요 없습니다.**

## 관리자 추가 · 변경
1. Authentication → 사용자 → 사용자 추가 (이메일 + 비밀번호)
2. `firestore.rules`의 이메일 목록에 추가 → 콘솔 규칙 탭에 다시 붙여넣고 **게시**

비밀번호를 잊었을 때: 로그인 화면의 「パスワードを忘れた方」 → 메일로 재설정

## 사용 팁

**週報・暗誦聖句**
- 날짜는 자동으로 「다음 주일」이 들어갑니다. 미리 등록해 두면 그 날짜가 되는 날부터 사이트에 표시됩니다(예약).
- 같은 날짜로 다시 등록하면 덮어씁니다. 「編集」에서 성구만 고치면 이미지는 그대로 남습니다.
- 주보는 앞면 → 뒷면 순서로 선택하세요.

**ハレルヤ食堂**
- 지난 날짜의 예정은 사이트에서 자동으로 사라집니다.
- 「複製」을 누르면 내용이 복사되니, 날짜만 바꿔서 다음 회차를 빠르게 등록할 수 있습니다.
- 식당 사진은 「アルバム」 탭에서 카테고리 「ハレルヤ食堂」으로 올리면 식당 페이지에도 나옵니다.

**アルバム**
- 여러 장을 한 번에 선택할 수 있습니다. 스마트폰 사진도 자동으로 줄여서 저장합니다 (목록용 작은 이미지 + 확대용 이미지).
- 얼굴이 나오는 사진은 본인·보호자 동의를 받은 것만 올려 주세요.

## 무료 한도 (Firebase Spark 요금제)
- 저장 용량 1GB — 사진 1장 약 0.1MB 기준으로 수천 장
- 하루 읽기 5만 회 — 앨범은 48장씩 나눠 불러오므로 교회 규모에서는 여유가 있습니다
- 한도를 넘으면 그날은 표시가 멈추고, 요금이 자동으로 청구되지는 않습니다
